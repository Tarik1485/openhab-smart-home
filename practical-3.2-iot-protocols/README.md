# Practical Work 3.2 — IoT Communication Protocols

## Topic
LoRaWAN, Zigbee mesh, CoAP, and energy-efficient agricultural monitoring.

## Implementation status
This project uses software simulations. Real radio range, physical OTAA
through TTN, and hardware power measurements require actual devices.

## Structure
- `src/lorawan` — LoRaWAN node and payload simulation.
- `src/zigbee` — mesh topology and route recovery.
- `src/coap` — CoAP resources and message exchange.
- `tests` — automated tests.
- `docs` — architecture and test results.
- `report` — final report.
- `simulations` — simulation scenarios.
