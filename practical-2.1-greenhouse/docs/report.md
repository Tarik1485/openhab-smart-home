Практична робота 2.1. Система моніторингу теплиці

Мета роботи

Розробити прототип системи моніторингу теплиці з використанням MQTT, Mosquitto, Python та openHAB. Навчитися передавати показники датчиків, отримувати їх через MQTT-канали та створювати правила автоматизації.

1. Архітектура системи

Система складається з таких компонентів:

Python-симулятор — генерує показники датчиків теплиці.

Mosquitto — MQTT-брокер, який приймає та передає повідомлення.

MQTT Binding в openHAB — забезпечує підключення до брокера.

Things, Channels та Items — забезпечують отримання й відображення показників.

Rules — реалізують перевірку порогових значень.

3. Налаштування MQTT

Для практичної роботи створено окрему конфігурацію Mosquitto з адресою 127.0.0.1 та портом 1885. Це дозволяє ізолювати тестове середовище від інших конфігурацій брокера.

У openHAB створено MQTT Bridge Greenhouse MQTT Broker та Thing Greenhouse Sensors. Для кожного показника налаштовано відповідний канал, а Items прив’язано до цих каналів.

4. Симулятор датчиків

Симулятор написаний мовою Python із використанням бібліотеки paho-mqtt. Він генерує випадкові значення температури, вологості, освітленості та інших показників і публікує їх через MQTT приблизно кожні п'ять секунд.

5. Правила автоматизації

Створено два правила:

Greenhouse - Low Soil Moisture — перевіряє вологість ґрунту та записує попередження, якщо значення нижче 30%.

Greenhouse - High Temperature — перевіряє температуру повітря та записує попередження, якщо значення вище 28 °C.

Фактичне спрацювання правил необхідно підтвердити повідомленнями в журналі openHAB.

Висновок

У ході практичної роботи створено прототип системи моніторингу теплиці. Реалізовано генерацію показників датчиків у Python, передавання даних через MQTT-брокер Mosquitto та отримання даних в openHAB. Передавання перевірено за допомогою MQTT-клієнта. Створено правила для контролю вологості ґрунту та температури повітря.

Для завершення звіту необхідно додати реальні скриншоти налаштувань openHAB, показників Items, MQTT-повідомлень і правил автоматизації.
