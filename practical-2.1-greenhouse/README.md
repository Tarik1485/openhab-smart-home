Практична робота 2.1 — Моніторинг теплиці

Опис

Прототип системи моніторингу теплиці на основі Python, MQTT, Mosquitto та openHAB.

Можливості

Генерація показників шести датчиків.

Передавання значень через MQTT.

Отримання показників в openHAB.

Контроль вологості ґрунту з порогом 30%.

Контроль температури повітря з порогом 28 °C.

Структура

config/ — конфігурація окремого MQTT-брокера.

simulator/ — Python-симулятор датчиків.

docs/ — звіт та документація.

logs/ — папка для журналів.

tests/ — папка для тестів.

Запуск

Запустити Mosquitto з конфігурацією config/mosquitto-greenhouse.conf.

Запустити симулятор:

python .\simulator\greenhouse_simulator.py

Перевірити MQTT-повідомлення:

& "C:\mosquitto\mosquitto_sub.exe" -h 127.0.0.1 -p 1885 -t "greenhouse/sensors/#" -v

Звіт

Докладний звіт: docs/report.md.

Примітка

Показники генеруються випадково. Значення якості повітря є демонстраційними, а не вимірюваннями каліброваного фізичного сенсора.
