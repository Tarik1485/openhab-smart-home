# Практична робота 3.1 — Мультипротокольна система в OpenHAB

## Мета роботи

Ознайомитися з підходом до об'єднання пристроїв різних протоколів у системі розумного будинку та перевірити обмін даними.

## Використані технології

| Технологія | Призначення | Реалізація |
|---|---|---|
| MQTT | Передавання телеметрії | Python-емулятор метеостанції та Mosquitto |
| HTTP/REST | Отримання даних через API | Python HTTP-сервер |
| BLE | Демонстрація даних Bluetooth-сенсора | Програмний емулятор BLE |
| OpenHAB | Платформа автоматизації | Локальне середовище OpenHAB 4.1.0 |
| Python | Емулятори та автоматичні тести | Python 3.12 |

## HTTP API

Сервер запускається командою:

```powershell
python ".\scripts\device_api.py"
```

Адреса сервера: `http://127.0.0.1:8090`

| Endpoint | Призначення |
|---|---|
| `/api/weather/current` | Температура, вологість, тиск і час |
| `/api/weather/status` | Статус HTTP-сервісу |
| `/api/devices` | Перелік емуляторів пристроїв |
| `/api/ble/scan` | Приклад даних BLE-сенсора |

## MQTT

Скрипт `scripts/mqtt_weather_station.py` призначений для передавання показників метеостанції через MQTT. Для реального підключення необхідні запущений брокер Mosquitto та правильні облікові дані.

Основні теми:
- `weather-station/temperature`
- `weather-station/humidity`
- `weather-station/pressure`
- `weather-station/rssi`
- `weather-station/status`

## BLE

BLE у цій роботі представлено програмною емуляцією. Це демонструє формат даних сенсора, але не є скануванням реального Bluetooth-пристрою.

## Автоматичні тести

Запуск тестів HTTP API:

```powershell
python -m unittest discover -s tests -v
```

Тести перевіряють доступність кінцевих точок, структуру JSON-відповідей та допустимі межі змодельованих показників.

## Обмеження

Наявність емулятора не означає, що відповідний протокол уже інтегрований у OpenHAB. Для повної інтеграції потрібно налаштувати відповідні binding-и, канали, Items та перевірити надходження значень у самій платформі.

## Висновок

У межах практичної підготовлено HTTP API, емулятор даних BLE-сенсора та MQTT-скрипт. Автоматичні тести дозволяють перевірити HTTP-ендпоїнти. Емуляція допомагає продемонструвати загальний підхід до роботи з кількома протоколами.
